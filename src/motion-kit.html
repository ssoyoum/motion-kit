Motion Kit 프론트 모션

로딩, 채팅, 피드백, 폼, 버튼, 텍스트, 전환, 내비게이션, 아이콘, 일러스트, 차트, 배경, 3D까지 프로젝트에 바로 붙이는 CSS 애니메이션입니다. '마우스를 올려 보세요'라고 적힌 카드는 실제 호버로 움직입니다. 라이브러리 없이 HTML과 CSS만 복사해 붙이면 됩니다. 색은 --mk-accent 같은 CSS 변수 하나로 바꿉니다.

시스템에서 '동작 줄이기'가 켜져 있어 멈춘 상태로 열었습니다. 재생을 누르면 움직입니다. 실제 서비스에서는 @media (prefers-reduced-motion: reduce)로 끄는 것을 권합니다.

모은 모션을 한 번에 가져갑니다.

아직 모은 모션이 없습니다. 카드 오른쪽 위 ★을 누르면 여기에 모입니다. 모은 목록은 이 브라우저에 저장됩니다.

모든 예시는 미리보기용으로 무한 반복합니다. 한 번만 재생하려면 infinite를 지우거나 animation-iteration-count: 1로 바꾸세요. 숫자 롤링·진행률·도넛·회전 테두리는 @property를, 아코디언은 grid-template-rows 전환을 씁니다 (Chrome·Edge·Safari 16.4+, Firefox 128+).
